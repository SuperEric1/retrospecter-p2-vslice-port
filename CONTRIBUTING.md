# Contributing

Thanks for wanting to help out with the port! Before opening an issue or pull request, please read this.

## Before opening an issue

- Search existing issues first — your bug or idea might already be tracked.
- Check [docs/TODO.md](docs/TODO.md) — if it's already listed there, no need to open a new issue, feel free to comment on an existing one instead (if there is one) or just wait for it.
- Use the issue template that fits (Bug Report or Feature Request). Issues that don't fill in the required info may be closed without a response.

## Reporting bugs

Include:
- What device/platform you're on (Android version, device model)
- Steps to reproduce
- What you expected vs what happened
- Logs/crash output if you have them (check polymod's log folder)
- Screenshots or video if it's visual

## Suggesting features

Keep in mind this is a **port**, not a new mod. Features that exist in the original PC mod but aren't in the port yet are welcome suggestions (check [docs/TODO.md](docs/TODO.md) first). Brand new features that don't exist in the original mod are less likely to be accepted, but feel free to suggest them anyway.

## Pull requests

- Open an issue first for anything non-trivial (new mechanics, big refactors), so we can discuss the approach before you put in the work.
- Keep PRs focused — one fix/feature per PR makes review easier.
- Match the existing code style:
  - Indentation is 2 spaces.
  - Don't add comments that just restate what the code already says.
- Test on an actual Android device (or emulator) before submitting, when possible.
- Reference the related issue number in your PR description, if there is one.

## What won't be accepted

- Re-adding content covered by the "DOESN'T have" list in the README without prior discussion (some of those exclusions are intentional, not just unfinished work).
- Code lifted from other mods/ports without proper credit and without checking it's okay to use.
- Anything that goes against the original mod's spirit/rules.

## Code of conduct

Be respectful. Disagreements about implementation are fine, hostility isn't. This project follows the same expectations as the rest of the FNF modding community: harassment, hate speech, or NSFW content involving the mod's characters in issues/PRs will get you blocked.
